📦 Game Bot Starter Kit (Go Native Engine)

Template arquitetural padronizado para criar novos bots ultraleves (2-5 MB de RAM) para qualquer jogo idle / browser e rodar 24/7 na VPS.

🚀 1. Criar para Novo Jogo

Duplique a pasta deste template e peça à IA para ler AI_INSTRUCTIONS.md:

cp -r bot-template-go meu-novo-bot

🔨 2. Compilar para VPS Linux

Gere o binário estático para Linux com o cmd Go nativo:

go run ./cmd/build linux

🛡️ 3. Deploy na VPS Ubuntu

Envie via SCP e configure como serviço permanente do systemd:

scp bot-app-linux ubuntu@seu-servidor-ip:~/
